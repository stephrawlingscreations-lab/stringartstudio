About Steph Rawlings Creations

Maker, software builder, and creator of tools that solve real problems — starting with string art, now building for clients too.

The maker behind the tools

I build software because I needed tools that didn't exist.

String art looks incredible when it's done right — but getting there isn't easy. Spacing nails evenly, planning the pattern, figuring out the sequence… it's where most people give up.

I kept running into the same problem: I had the idea, but no easy way to turn it into something I could actually build. So I taught myself to code and built the String Art Designer from scratch.

That same mindset is how I work with clients today — understand the real workflow, then build something practical.

About me

Based in Ireland

I originally got into string art because I loved how it looked — but I quickly realised how frustrating it could be to actually plan and build a piece properly.

I came at string art as a hands-on maker: learning by doing, testing patterns on real boards, and building up a feel for what works through direct experience — not from a textbook.

At the same time, I've been dealing with ongoing health issues, and I found that working on string art really helped my mental health — it gave me something to focus on and switch off.

That's what pushed me to create this tool. Something that lets you test ideas, adjust designs, and get it right before you start using real materials.

I built the tool from scratch because nothing else gave makers real control. Most tools online auto-generate a pattern from a photo — but I wanted something you could actually design with: set your nail spacing, test thread paths, plan layer by layer, and know before you commit a single nail that it'll come out right.

What started as a small idea turned into a full tool, and I'm still improving it every day based on what works (and what doesn't).
