Steph String Art Manual Mode (Numbered)
==================================

New:
- Numbers around the outside of the nails
- Control how often numbers show (Every N nails)
- Choose numbering style: start at 1 or start at 0
- Change number size + how far outside they sit

Notes:
- For 150 nails on a phone, use Every N nails = 10 or 15 so it stays readable.
- 'Fit preview to screen' leaves extra margin so the numbers don't get cut off.
