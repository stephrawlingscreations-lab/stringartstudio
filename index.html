Interactive String Art Board Designer

Create precise, print-ready numbered layouts in seconds

How to use
  • Choose a board shape and number of nails.
  • Turn numbering on/off and set Number every (e.g. 10 or 20).
  • Click/tap nails to draw your thread path.
  • Use layers to separate colours, and undo if you make a mistake.
  • Copy your sequence or download a PNG for printing.
